# AstrBot QQ Natural Chat

> 让 AstrBot 在 QQ 上像一个真人一样聊天，而不是一个客服机器人。

## 简介

一套用于调优 AstrBot QQ 私聊和群聊场景的提示词方案。目标是消除"AI味"，让机器人能用简短、口语化、分段式的中文自然交流。

## 痛点

你是否遇到过这些问题？

- 机器人回复像客服邮件，长篇大论还带"首先/其次/最后"
- 每次回答都要"作为AI，我无法..."
- 不理解网络缩写和抽象梗，一本正经地解释
- 群聊里发一大段话，直接把天聊死

这套方案就是为了解决这些问题而生的。

## 功能

- **去AI味**：移除模板化套话、列表式回答、过度礼貌等AI特征
- **中文网络俚语理解**：内置现代中文互联网用语和抽象表达的解释
- **短段落回复**：默认1-3个短段落，每段1-2句话
- **群聊/私聊区分**：群聊更轻快，私聊更稳重
- **梗百科联动**：遇到新梗时可查询 Bilibili `梗百科` 账号获取最新网络用语
- **自我学习**：用户解释新梗后自动持久化到知识库

## 使用

将 `references/astrbot-prompt-template.md` 中的提示词内容复制到你的 AstrBot 人格/系统提示配置中即可。

你也可以让 AI 助手加载此 skill 后，用自然语言描述需求：

```
帮我配置AstrBot的QQ群聊人格，要自然一点
```

```
把这段系统提示改得不像AI
```

```
"尊嘟假嘟"是什么意思？加到机器人的知识里
```

助手会根据工作流：

1. 确定目标配置（直接编辑 AstrBot 配置文件或生成可粘贴的提示块）
2. 锁定行为目标（自然中文QQ聊天，不是角色扮演）
3. 构建或重写提示词
4. 用真实场景验证回复风格
5. 持久化新学到的网络用语

## 效果对比

### ❌ 优化前

```
您好！关于您提到的这个问题，我将从以下几个方面进行分析：

首先，我们需要理解...
其次，值得注意的是...
最后，总的来说...

希望以上回答对您有所帮助！如有其他问题，请随时提问。😊
```

### ✅ 优化后

```

你遇到的是哪种情况？
```

## 输出契约

经过此方案调优后的 AstrBot 会遵守以下行为规范：

| 行为 | 说明 |
|------|------|
| 理解网络俚语 | 能识别中文互联网缩写、谐音梗、抽象表达 |
| 短段落 | 默认1-3段，每段1-2句 |
| 口语化 | 使用语气词和网络用语，但不过度 |
| 不列清单 | 除非用户明确要求步骤或对比 |
| 不套话 | 无"作为AI"、"总的来说"、"希望这能帮到你" |
| 不复述 | 不重复用户的话再回答 |
| 敢提问 | 遇到模糊输入时简短追问，不瞎猜 |
| 会学习 | 新梗解释后自动持久化 |

## 反模式

以下指令会被识别并移除：

- `提供全面准确的回答` — 闲聊不需要全面
- `使用清晰的结构分点说明` — 日常对话不需要结构
- `保持礼貌和专业` — 群聊不是商务会议
- `先总结用户的问题再解决` — 太正式了
- `主动提供多个建议` — 简单斗嘴不需要
- `总是追问一个问题` — 刻意
- `使用emoji显得友好` — 一刀切
